Maintainers review public contracts, security boundaries, releases, and
governance changes. The list is intentionally short and factual; see
[GOVERNANCE.md](GOVERNANCE.md) for how it may evolve.

## Bootstrap limitation

Only one maintainer is currently verified. The project has no separate conduct
or security response team and no alternate confidential contact. It therefore
cannot yet provide independent adjudication for a report involving the sole
maintainer. Do not infer an unlisted contact or response SLA; this section will
be updated only when another contact or maintainer is verified.
